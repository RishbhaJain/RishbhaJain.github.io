# CS 180/280A: Project 0

A responsive static project page for **Becoming Friends with Your Camera**.

## Preview locally

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Add the photos

Place the final files in `images/` using the filenames documented in
[`images/README.md`](images/README.md). Missing images intentionally render as
designed placeholders rather than broken image icons.

## Publish with GitHub Pages

1. Create a GitHub repository and push this folder to its `main` branch.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The published URL will usually be
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
